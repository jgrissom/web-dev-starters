# .NET Web Development — Lab Starters

Starter code for each week's lab. Weeks appear here as they're released.

## First time (week 1)

```bash
git clone https://github.com/jgrissom/web-dev-starters.git
```

## Every week after

```bash
cd web-dev-starters
git pull
```

Then **copy the week's folder OUT of this clone** into your own projects folder and work on the copy:

```bash
cp -r week-02 ~/projects/week-02-lab     # Mac/Linux
# or just copy-paste the folder in Explorer/Finder
```

## Rules

- **Never edit files inside this clone** — it's download-only. If you work in your own copy, `git pull` always works cleanly and you always have the latest fixes.
- Your own work goes in your own folders (and eventually your own repos).
